# Microprocessor Simulator — Compact Version

A smaller educational variant of the microprocessor simulator. It models 16-bit and 8-bit registers and runs a subset of assembly instructions through an interactive shell.

## Requirements

- Python 3.10 or newer

## Run

```bash
cd simulator_less_advanced
python3 Zad5.py
```

At the prompt, load the included program and run it:

```text
load demo.asm
run
```

Use `help` to see the available commands.
